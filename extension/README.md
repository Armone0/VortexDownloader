# VortexDownloader Browser Extension ⚡

Companion Manifest V3 browser extension for Google Chrome, Microsoft Edge, and Chromium-based browsers.

## 🚀 Features
- **Seamless Download Capture:** Automatically intercepts browser file downloads and hands them over to the ultra-fast VortexDownloader engine (`http://127.0.0.1:19741/download/`).
- **Zero-Drop Fallback:** If VortexDownloader desktop app is not running or rejected, downloads automatically resume natively in the browser without failure.
- **Privacy & Security:** No third-party network requests, no analytics tracking, no external script injection.

## 📦 Installation (Developer Mode)
1. Open your browser and navigate to:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
2. Enable **Developer Mode** (top-right toggle).
3. Click **Load unpacked** (Paketlenmemiş öğe yükle).
4. Select this `extension` folder.
5. Ensure VortexDownloader desktop app is running. Any file download initiated in the browser will now trigger the instant Vortex download prompt!
